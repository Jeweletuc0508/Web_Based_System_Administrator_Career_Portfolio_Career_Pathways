# System Administrator Career E-Portfolio

A responsive, single-page student career portfolio inspired by the supplied Canva reference: dark navy background, cyan highlights, thin technical grid, outlined cards, geometric server illustration, and clean typography.

## Files
- `index.html` — content and sections
- `styles.css` — visual design and responsive layouts
- `script.js` — mobile navigation, active section state, and dynamic footer year

## Run locally
Open `index.html` in a modern browser. Internet is only needed for the optional Google Font and links to official learning resources.

## Personalize before submission
In `index.html`, replace:
- `[Your Name]`
- `[Your Course or Program]`
- `your.email@example.com`

Review the profile text so it reflects your own details and career goals. The site includes Home, Career Pathway, Skills & Qualifications, Job Roles & Responsibilities, Skills & Tools, and About the Developer.
